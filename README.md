# 医生科普发布工具包

**把一个医学选题，做成有来源、能审核、可排版的公众号文章包。**

v0.2 公开试用版。面向医生、诊所内容负责人和医学科普编辑。输入选题、读者和品牌信息；输出中文文章、主张对应来源、HTML文字排版、配图任务单及医生审核清单。

## 安装与使用

把 `skills/doctor-wechat-publisher` 整个文件夹复制到你的 Codex 用户技能目录 `~/.codex/skills/`，目录已存在时先比较内容，不直接覆盖。开启新任务后输入：

> 使用 $doctor-wechat-publisher，为普通成年读者制作一篇鼻出血科普审核稿。品牌按附带演示配置，附来源、HTML和配图任务单。

这是提供给AI助手的Skill，不是双击即运行的独立应用。文章生产需要能读取技能文件、写文件并查阅网页的AI环境；使用费用由所用平台决定。本次交付为可安装目录，未修改你的本机全局技能目录。

本地排版脚本需要Python 3，无额外依赖。从仓库根目录运行：

```bash
python3 skills/doctor-wechat-publisher/scripts/render_package.py examples/nosebleed/article.json --out work/nosebleed-preview
```

浏览器打开生成的HTML；复制其中文章区域，粘贴到微信编辑器，再做微信预览。HTML未内置复制按钮；引用链接可能需按平台规则调整，图片另行上传。本版不声称微信样式完全保真。
